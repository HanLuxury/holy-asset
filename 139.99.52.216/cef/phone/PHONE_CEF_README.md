# EAGLE smartphone_new CEF

This feature replaces the smartphone_new TextDraw presentation layer.

URL:
`https://hanluxury.github.io/holy-asset/139.99.52.216/cef/phone/index.html`

The page is transparent, responsive, uses FontAwesome CDN, and talks to the Pawn bridge through `nativeSendEvent`.

Main events: `phone.ready`, `phone.refresh`, `phone.tab`, `phone.call`, `phone.contacts.*`, `phone.whatsapp.send`, `phone.twitter.*`, `phone.yellow.*`, `phone.bank.history`, `phone.bank.transfer`, `phone.vehicle.*`, `phone.transport.order`, `phone.gps.set`, `phone.airdrop.*`, `phone.settings.*`, `phone.service.send`, `phone.spotify.*`, `phone.pay`.
