# Inventory icon system

Inventory icons are PNG RGBA assets under `cef/inventory/assets/items/<itemid>.png`.

The visual style is a FiveM/GTA-inspired cutout: realistic isolated object, transparent background, no circular badge and no colored icon frame.

The frontend resolves icons from the server-provided `itemid`, so icon mapping stays synchronized with the inventory catalogue.

The generated assets are a custom FiveM-inspired pack, not extracted proprietary FiveM/GTA V artwork.
